# Происхождение и лицензия

Скилл — производная работа от проекта **watermarks-remover**:
https://github.com/guillaumemeyer/watermarks-remover/tree/main

Автор оригинала — Guillaume Meyer и контрибьюторы, лицензия MIT. Текст лицензии
сохранён в файле `LICENSE` вместе с копирайтом правообладателя.

## Что взято из оригинала без изменений

- `scripts/inspect_text.py`, `scripts/clean_text.py`, `scripts/text_unicode.py`,
  `scripts/common.py` — слой A: поиск и вычистка невидимых Unicode-символов
- `references/watermark-notes.md`, `references/responsible-use.md`

## Что изменено

- `SKILL.md` переведён на русский и адаптирован: убраны привязки к Cursor,
  описание переписано под то, как скилл вызывается в наших задачах.

## Чего в этой версии нет по сравнению с оригиналом

Оригинал закрывает гораздо больше: работу с изображениями, C2PA и метаданными
файлов (PNG, JPEG, WebP, SVG, PDF, DOCX, ODT), HTTP-сервис с Docker-образами,
внешние бэкенды для пиксельных водяных знаков. Здесь остался только текст.
Если нужны файлы и метаданные — берите оригинал.

## Область применения

Скилл предназначен для текстов, которыми вы владеете или которые вправе
обрабатывать. Он не предназначен для того, чтобы выдавать текст за написанный
человеком там, где раскрытие использования ИИ обязательно, — см.
`references/responsible-use.md`.
